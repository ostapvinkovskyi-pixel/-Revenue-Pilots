# Builder Pilot Autonomy Levels

Level 0 — Observe/log only.
Level 1 — Prepare drafts/build plans.
Level 2 — Modify an isolated branch, run checks, create/update a PR and preview.
Level 3 — Perform bounded repair attempts after deterministic failures.
Level 4 — Production merge/deploy only after an explicit owner approval for the exact commit SHA.

Current Builder Pilot target before LaunchPad: Level 2 with bounded Level 3 repairs. Level 4 remains owner-gated.
