# Revenue Pilots Automation Control Files

This directory contains machine-readable operating contracts for the internal Business Autopilot.

- `BUILDER_JOB_SCHEMA.md` — required BUILD_JOB contract and state machine.
- `OWNER_APPROVAL_POLICY.md` — single-use production approval rules.
- `QA_POLICY.md` — minimum deterministic + preview QA gates.

These files are operating policy, not customer content. They must not contain passwords, API keys, OAuth tokens, or client secrets.
